# Standard Operating Procedures

## Overview
Executes business workflows according to explicit Standard Operating Procedure (SOP) state machine definitions. Ensures stage transitions only occur upon meeting pre-specified criteria and schema validation.

## Key Capabilities
- Linear, conditional, and cyclic stage progression.
- Guard condition validation before transitioning state.
- Rollback and checkpoint resumption upon step failure.
