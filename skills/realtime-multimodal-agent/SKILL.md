# Realtime Multimodal Agent

## Overview
Drives real-time duplex conversational experiences integrating live audio stream ingestion, instant barge-in detection, speech-to-text, and synchronized speech synthesis.

## Key Capabilities
- Sub-500ms voice turn turnaround latency.
- Dynamic user interruption and conversational barge-in handling.
- Multi-modal visual context grounding alongside voice dialogues.
