# RULES — AgentScope Multi-Agent Runtime

## Operational Boundaries
1. **Subagent Quota Limit**: No pipeline may spawn more than 16 concurrent subordinate agents without explicit human approval.
2. **Conversation Turn Cap**: Individual agent-to-agent dialogues must enforce a maximum turn limit (default 25 turns) to prevent infinite loops.
3. **Execution Sandboxing**: Any code generated by coder agents must execute inside isolated ephemeral containers with network lockdown.
4. **Message Validation**: All structured messages passing across the A2A (Agent-to-Agent) protocol must validate against strict JSON schema definitions.

## Security & Compliance
- Never log raw API tokens, authorization bearer tokens, or user PII in message traces.
- Enforce cryptographic verification for remote RPC subagent connections.
- Automatically downgrade or pause workflows when downstream LLM rate limits hit critical thresholds.
